System Architecture Overview
🖥️

Frontend (React)

Single Page Application with React 18, Vite, Redux Toolkit for state, React Router for navigation, and Tailwind CSS for styling.

  • React 18 + Vite
  • Redux Toolkit + RTK Query
  • React Router v6
  • Tailwind CSS + shadcn/ui
  • React Hook Form + Zod
  • Axios for API calls
⚙️

Backend (Node + Express)

RESTful API server with JWT authentication, role-based access, file uploads via Cloudinary, and comprehensive middleware.

  • Node.js + Express 4
  • JWT + Bcrypt Auth
  • Multer + Cloudinary
  • Express Validator
  • Morgan + Winston logs
  • CORS + Helmet security
🗄️

Database (MongoDB)

NoSQL document database with Mongoose ODM, indexed queries for performance, and well-structured schemas with relationships.

  • MongoDB Atlas (cloud)
  • Mongoose v7 ODM
  • Text search indexes
  • Aggregation pipelines
  • GridFS for large files
  • Transactions support
🔐

Authentication

Secure JWT-based auth with access + refresh tokens, HTTP-only cookies, Google OAuth optional, and protected route guards.

  • Access Token (15 min)
  • Refresh Token (7 days)
  • HTTP-only cookies
  • Google OAuth 2.0
  • Email verification
  • Password reset flow
☁️

Media & Storage

Image upload pipeline with Multer middleware, Cloudinary CDN storage, automatic resizing and optimization.

  • Multer file upload
  • Cloudinary CDN
  • Image auto-resize
  • WebP conversion
  • Lazy loading on FE
🚀

Deployment

Production-ready deployment with CI/CD pipeline, Docker containers, and cloud hosting for both frontend and backend.

  • Frontend → Vercel
  • Backend → Railway / Render
  • DB → MongoDB Atlas
  • Docker + docker-compose
  • GitHub Actions CI/CD
  • ENV-based config

REST API Endpoints
🔑 Auth Routes — /api/auth
POST/api/auth/registerRegister new user, send verification emailPublic
POST/api/auth/loginLogin with email/password, return JWT tokensPublic
POST/api/auth/logoutLogout user, clear refresh token cookiePrivate
POST/api/auth/refresh-tokenGet new access token using refresh tokenPublic
GET/api/auth/verify-email/:tokenVerify email address from linkPublic
POST/api/auth/forgot-passwordSend password reset emailPublic
POST/api/auth/reset-password/:tokenReset password using token from emailPublic
GET/api/auth/googleInitiate Google OAuth 2.0 flowPublic
👤 User Routes — /api/users
GET/api/users/meGet current logged-in user profilePrivate
PUT/api/users/meUpdate profile (name, bio, avatar)Private
DELETE/api/users/meDelete user account and all associated dataPrivate
GET/api/users/:usernameView public profile of any user by usernamePublic
POST/api/users/:id/followFollow or unfollow a user (toggle)Private
GET/api/users/:id/followersGet list of user's followersPublic
GET/api/users/:id/followingGet list of users that this user followsPublic
GET/api/users/me/saved-recipesGet all recipes saved/bookmarked by userPrivate
🍲 Recipe Routes — /api/recipes
GET/api/recipesGet all published recipes (pagination, filter, sort)Public
GET/api/recipes/search?q=Full-text search by title, tag, ingredientPublic
GET/api/recipes/trendingGet trending recipes (by likes + views)Public
GET/api/recipes/feedPersonalized feed from followed usersPrivate
GET/api/recipes/:slugGet single recipe by slug, increment viewsPublic
POST/api/recipesCreate new recipe (with image upload)Private
PUT/api/recipes/:idUpdate recipe (author only)Private
DELETE/api/recipes/:idDelete recipe and its comments (author only)Private
POST/api/recipes/:id/likeLike or unlike recipe (toggle)Private
POST/api/recipes/:id/saveSave or unsave recipe to bookmarks (toggle)Private
GET/api/recipes/user/:userIdGet all recipes by a specific userPublic
💬 Comment Routes — /api/recipes/:id/comments
GET/api/recipes/:id/commentsGet all comments for a recipe (paginated)Public
POST/api/recipes/:id/commentsPost a new comment on a recipePrivate
PUT/api/comments/:commentIdEdit comment (author only)Private
DELETE/api/comments/:commentIdDelete comment (author or recipe author)Private

Key React Components
🃏

RecipeCard

Cover image, title, author, cook time, likes count, save button. Used in grids and feeds.

📝

RecipeForm

Create/Edit form with dynamic ingredient rows, step reordering, image upload, and tag input.

👤

UserAvatar

Avatar with online indicator, size variants, fallback initials when no image is set.

➕

FollowButton

Toggle follow/unfollow with optimistic UI update and follower count display.

❤️

LikeButton

Animated like toggle with count. Updates Redux state optimistically on click.

🔖

SaveButton

Bookmark recipe. Persists to user's saved list. Toast feedback on save/unsave.

🔍

SearchBar

Debounced search with autocomplete dropdown, supports ingredient and tag filters.

💬

CommentSection

Threaded comments with replies, like support, pagination, and author controls.

🏷️

TagFilter

Clickable category/cuisine/difficulty chips for filtering recipe lists.

📊

DashboardStats

Shows total recipes, likes received, followers, and views in metric cards.

🛡️

ProtectedRoute

HOC that redirects unauthenticated users to login. Wraps private pages.

🔔

Toast / Alerts

Global notification system for success, error, and info messages via Redux.
